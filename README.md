# Blinkit Sales Performance Dashboard

## 📊 Project Overview
This project presents an **interactive Power BI dashboard** built to analyze Blinkit's sales performance, customer satisfaction, and inventory distribution.  
The dashboard provides actionable insights through key performance indicators (KPIs) and advanced visualizations.

## ⚙️ Data Processing
- **Data Source:** Blinkit sales and inventory dataset  
- **SQL (ETL):**
  - Extracted and transformed sales data using **SQL queries** (joins, aggregations).  
  - Automated ETL pipelines for cleaning and preparing data.  
- **Power BI:** Developed dashboards with **DAX measures, drill-through filters, and slicers** for ad-hoc analysis.

## 📈 Key Features
- **KPIs Tracked:**
  - Total Sales: **$1.2M**
  - Number of Items Sold: **8.52K**
  - Average Sales: **$141**
  - Average Rating: **3.92**
- **Category-wise Insights:** Sales trends by item type (Fruits, Snacks, Household, Dairy, etc.)
- **Customer Insights:** Ratings and price distribution.
- **Geographical & Store Analysis:**
  - Outlet performance by **size, type, and location tiers**.
  - Outlet establishment trends over time.
- **Inventory Distribution:** Sales patterns by fat content (Low Fat, Regular).

## 🚀 Impact
The dashboard improved **decision-making** by delivering:
- A clear view of **overall sales performance**.  
- Category-wise and location-wise sales trends.  
- Better understanding of **customer satisfaction and inventory distribution**.  

## 🛠️ Tools & Technologies
- **SQL** – Data extraction, joins, aggregations, ETL pipeline.  
- **Power BI** – Interactive visualizations, KPIs, DAX calculations, drill-through analysis.
